## 📋 Descripción del Proyecto

Periscan AI es una plataforma digital innovadora que transforma el proceso tradicional de assessment empresarial de Periferia IT Group de 6 semanas a una experiencia interactiva, dinámica y potenciada con Inteligencia Artificial que entrega resultados inmediatos.

La solución convierte el diagnóstico de dolores empresariales en un flujo conversacional inteligente que identifica problemas críticos y genera propuestas estratégicas estructuradas en corto, mediano y largo plazo.

## 🏗️ Arquitectura y Tecnologías

### Frontend
- **Framework**: Next.js 16.0.0 (React)
- **Styling**: Tailwind CSS + shadcn/ui
- **TypeScript**: Tipado estático completo
- **Deployment**: Vercel

### Backend/API
- **Runtime**: Node.js con Next.js API Routes
- **IA**: Groq SDK (LLaMA 3 70B)
- **Processing**: Análisis de texto y generación de insights

### Herramientas de Desarrollo
- **V0.dev**: Prototipado rápido de componentes UI
- **GitHub Copilot**: Asistencia en desarrollo
- **ChatGPT**: Refinamiento de prompts y lógica de IA
